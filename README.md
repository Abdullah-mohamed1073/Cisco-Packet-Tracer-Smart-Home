# Smart Home IoT Simulation - Cisco Packet Tracer

## Overview
This project is a comprehensive Smart Home network simulation designed using **Cisco Packet Tracer**. It demonstrates the implementation of Internet of Things (IoT) devices in a modern home environment, allowing centralized control and automation through a Home Gateway.

## Key Features & IoT Devices
The simulation includes several automated and remotely controlled systems:
* 🚘 **Smart Garage Door:** Automated garage access that can be controlled remotely.
* 💡 **Smart Lighting System:** Connected lights that can be turned on/off or dimmed for energy efficiency.
* ❄️ **Climate Control (Smart AC):** Smart air conditioning units for temperature regulation.
* 🌱 **Automated Irrigation System (Water Sprinklers):** A smart watering system for the garden/plants to ensure efficient water usage.

## Network Architecture
* **Home Gateway:** Acts as the central hub connecting all IoT devices to the local network.
* **Control Device:** A Smartphone or PC connected to the network, used to monitor and manage all smart devices through the IoT server interface.
* **Connection:** Devices are connected wirelessly and configured with the appropriate IP addressing scheme.

## How to Run the Simulation
1. Make sure you have **Cisco Packet Tracer** installed on your machine.
2. Download the `Smart_Home.pkt` file from this repository.
3. Open the file in Packet Tracer.
4. Click on the Smartphone/PC in the simulation, open the Web Browser, and log in to the IoT Server to control the devices (Garage, Lights, AC, and Sprinklers).
